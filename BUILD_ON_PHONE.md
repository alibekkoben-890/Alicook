# Ali Cook — сборка APK на GitHub с телефона

1. Создайте новый приватный репозиторий GitHub, например `AliCook-Android`.
2. Загрузите **содержимое** этого архива в корень репозитория (файлы `settings.gradle`, `build.gradle`, папки `app` и `.github`). GitHub в мобильном браузере может потребовать режим «Версия для ПК».
3. Откройте вкладку Actions → Build Ali Cook APK → Run workflow → Run workflow.
4. Дождитесь зелёной отметки. Откройте выполненный запуск и скачайте `AliCook-APK` в разделе Artifacts.
5. Распакуйте ZIP и установите `app-release.apk` на Android, разрешив установку из выбранного приложения, если Android запросит это.

Сборка подписана постоянным ключом из секретов репозитория (ALICOOK_*), поэтому новые версии ставятся поверх старой. Это сборка для личной установки, не релиз для Google Play. Если Actions не виден, проверьте настройки Actions репозитория. Если сборка завершилась ошибкой, откройте лог шага Build release APK.
