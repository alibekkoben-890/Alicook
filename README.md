## Что нового в 1.75
- Таймер готовки звонит вовремя, даже если телефон заблокирован или приложение свёрнуто (системный будильник и уведомление); понимает время в часах и несколько времён в одном шаге.
- Поворот экрана и смена тёмной темы больше не закрывают открытый рецепт; после выгрузки приложения системой рецепт и шаг готовки открываются снова.
- Количество продуктов в привычных единицах (штуки, зубчики, ложки, стаканы, мл), граммы — в скобках.
- Компактная шапка: фильтры сворачиваются; поиск исправляет опечатки.
- Продукты в подборе разбиты на группы; на ужин в меню недели не попадают выпечка и сладкое; у каждого дня — калории.
- Резервная копия избранного, заметок, списка покупок и меню (⚙ Настройки).
- Подсказки для плиты учитывают шаги с несколькими действиями; 64 рецепта с короткими шагами переписаны подробно, ещё в 58 рецептах в шаги добавлено время.
- Отступы под системные панели Android 15.

## Сборка APK
1. Откройте эту папку в Android Studio с установленным Android SDK 35 и JDK 17.
2. Дождитесь Gradle Sync.
3. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Файл APK появится в app/build/outputs/apk/debug/ (подписанная сборка для установки делается в GitHub Actions, см. BUILD_ON_PHONE.md).

В архиве нет Gradle Wrapper и готового APK: Android Studio использует установленный Gradle или предложит настройку.
Калорийность приблизительная на весь рецепт. Для публикации потребуется тестирование и настройка современных Android API.

Данные встроены в index.html, чтобы работать в WebView без fetch(file://). Указана версия Android Gradle Plugin 8.7.3. APK в этой среде не собирался из-за отсутствия Android SDK и Gradle.
